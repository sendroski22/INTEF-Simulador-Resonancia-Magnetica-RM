Accesibilidad general en el simulador
El simulador comprende un orden genérico de tabulación que está dividido en dos grupos, uno de ellos se utiliza para controlar las funciones de la interfaz y el otro las de los contenidos. De este modo, se consigue una manera comprensiva y organizada para navegar entre las posibles interacciones. Las combinaciones de teclado definidas son: - Tab + Ctrl: permite avanzar de entre los grupos de tabulación - Tab + Shift: permite retroceder dentro del orden tabular de navegación establecido para el acceso a los elementos de la pantalla. - Tab: permite avanzar dentro del orden tabular de navegación establecido y acceder así a los diferentes elementos de la pantalla. - Enter: ejecuta el 'clic' del elemento seleccionado a través de teclado.
